# Stories Studio

**Скилл для Claude, который превращает текст поста в колоду Instagram-Stories** — с редакторской раскладкой по слайдам, автоматическим мудбордом из картинок интернета и браузерным редактором, из которого карточки выгружаются в PNG/JPEG.

Главный принцип: скилл **раскладывает** текст, а не переписывает его. Мысль, порядок и голос автора сохраняются: текст разбивается на слайды, размечается акцентами и получает ритм фонов и паттернов. Опечатки исправляются, а внутри абзаца можно убрать дубли — если не попросить «слово в слово».

---

## Что он делает

1. **Разбивает пост на 8–15 карточек** по редакторским правилам: первый слайд — заголовок, дальше чередуются паттерны (абзац, крупная цитата, список, финал), а фоны идут ритмом — белый / серый / изредка чёрный или один акцентный цвет.
2. **Собирает мудборд** (по желанию): несколько параллельных поисковых агентов приносят 60–90 картинок по темам поста, лучшие сразу вставляются в карточки, а остальные складываются в попап-галерею внутри редактора.
3. **Отдаёт живой редактор** — один HTML-файл, который открывается в браузере. Текст правится прямо на карточке, картинки переносятся мышью, меняются перетаскиванием файла или ссылкой, а готовые слайды выгружаются в PNG или JPEG.

## Установка

Клонируй репозиторий в папку скиллов Claude:

```bash
git clone https://github.com/<you>/stories-studio.git ~/.claude/skills/stories-studio
```

Дальше в Claude Code (или в другой среде, где работают скиллы) достаточно попросить: **«сделай stories из этого поста»** или **«сделай сторис с мудбордом»** — скилл подхватится сам.

Ручной запуск без Claude тоже возможен: скопируй `assets/template.html` в `stories.html`, `assets/server.py` рядом, положи картинки в `images/` и открой через локальный сервер (см. ниже).

## Зависимости

- **Python 3** — для локального сервера с прокси (нужен, чтобы экспорт мог забирать внешние картинки без CORS-ошибки).
- **Современный браузер** (Chrome, Safari, Firefox).
- **Интернет** — html2canvas и шрифты грузятся с CDN.
- Для шага с мудбордом — любой доступный веб-поиск (встроенный `WebSearch` или Exa MCP).

## Как пользоваться

```bash
# внутри папки, куда развернулась колода
python3 server.py 8089
open http://localhost:8089/stories.html
```

Сервер должен остаться запущенным — без него не сработает экспорт внешних картинок.

### Возможности редактора

- **Панель свойств у края экрана** — как в Figma: выбираешь текст или картинку, справа открываются их настройки; когда ничего не выбрано — настройки слайда. Ничего не вылезает за экран.
- **Текст** — правится прямо на карточке. Размер (S/M/L, точный кегль, интервал строк), 10 кириллических шрифтов, выравнивание, цвет, ширина блока тянется за край. `Ctrl+B` и `Ctrl+I` работают.
- **Выделения и плашки** — девять стилей: заливка, плашка, маркер, линия, контур, зачёркивание и три рукописных (обвести, подчеркнуть маркером, карандашом). У слова одно выделение: новое заменяет старое, без выделения стиль и цвет меняются у всех выделений блока.
- **Картинки** — перенос мышью, масштаб 20–400 %, поворот (ползунок или за углы), обрезка за 4 ручки, форма (как есть, скругление, круг), растяжка в фон с любой стороны — «как фон» делает край фото прозрачным. Замена файлом, ссылкой, перетаскиванием или из мудборда.
- **Фон слайда** — палитра, пипетка любого цвета, картинка фона из галереи или своим файлом. На тёмном фоне текст сам становится белым. Свои фоны в галерею добавляет `assets/backgrounds/add_backgrounds.py`.
- **Блоки и слайды** — «+ Текст», «+ Картинка», перенос в любую сторону, слои, «Дубль» слайда; ⌫ удаляет выбранный блок.
- **Отмена** — `⌘Z` / `⇧⌘Z`, 60 шагов, работает и посреди набора текста.
- **Формат** — 9:16 (Stories/Reels), 4:5 (пост) и 16:9 (обложка), на всю колоду; «Поля» показывают безопасные отступы.
- **Подпись** — при первом открытии редактор спрашивает адрес блога или имя для угла карточек; поменять — кнопкой «Подпись».
- **Сохранение и экспорт** — «Сохранить» или `Cmd+S` пишет вёрстку обратно в HTML (прежняя версия — в `*.backup.html`); «PNG» выгружает открытый слайд, меню «Экспорт» — JPEG и все слайды сразу.

Готовую колоду от прошлой версии можно перенести в новый движок: `python3 scripts/upgrade_deck.py старый.html новый.html`.

## Как устроено

- **`assets/template.html`** — весь редактор в одном файле: HTML-разметка карточек, CSS и ванильный JavaScript. Ни фреймворков, ни сборки.
- **`assets/server.py`** — маленький HTTP-сервер на стандартной библиотеке Python: эндпоинт `/proxy?url=…` (через него html2canvas забирает внешние картинки для экспорта) и `/save` (приём `Cmd+S`: бэкап прежней версии и атомарная запись файла).
- **`references/`** — правила раскладки (`composition-rules.md`), готовые HTML-снипеты слайдов (`slide-templates.md`) и инструкция по сбору картинок (`image-search.md`). Отсюда скилл берёт логику вёрстки.
- **`scripts/verify_text.py`** — сверяет текст готовых слайдов с исходником посимвольно, чтобы гарантировать: раскладка ничего не переписала.

Подробный алгоритм для Claude — в [`SKILL.md`](SKILL.md).
