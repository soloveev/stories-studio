# Правила композиции Stories

Эти правила применяются всегда, когда по тексту поста собирается Stories-раскладка. Цель — редакторская подача: ритм, разнообразие, читаемость на телефоне.

---

## ⛔ ПРАВИЛО НОЛЬ — ТЕКСТ НЕ РЕДАКТИРУЕТСЯ

**До всех остальных правил.** Перед тем как читать что-то ниже — впитай это:

Stories — это **раскладка** поста по слайдам, а не редактура. Текст автора попадает на слайды посимвольно тот же, что и в источнике. Единственные допустимые изменения:

| Можно | Нельзя |
|---|---|
| Разбить длинный абзац на 2 слайда по смысловой границе | Сократить предложение, выкинуть оборот |
| Обернуть слово в `<b>` / `<i>` для акцента | Заменить слово на синоним |
| Переставить картинку относительно текста | Поменять порядок предложений |
| Выбрать паттерн (BODY / QUOTE / BULLETS) | Перефразировать «по-журнальному» |
| Исправить очевидную опечатку («Бегищим» → «Бегущим», «оригнальной» → «оригинальной») | Трогать намеренные колоквиализмы автора («ии», «наративы», «телеграмм») |
| | «Доделать» пунктуацию, тире, кавычки |

### Проверка перед сдачей

После сборки слайдов: вытащи весь текст без HTML-тегов, склей в строку, сравни с `source.md`. Должно совпадать **посимвольно**, кроме тегов `<b>`/`<i>`, разрывов слайдов и исправленных очевидных опечаток — каждое исправление перечислить пользователю.

Если соблазн «причесать» или «улучшить» возникает — это запах того, что задача интерпретирована неправильно. Раскладывать = расставлять, не править.

## Базовые правила раскладки

### 1. На каждом слайде — картинка + текст

- Без текста слайдов не бывает. Даже чистый «image-only» формат с одной картинкой всё равно несёт футер.
- Без картинки слайдов тоже не бывает. Дефолтный плейсхолдер — `images/placeholder.svg` (нейтральный серый SVG). Пользователь меняет его потом drag-and-drop'ом / кнопкой / URL'ом.
- Под каждым слайдом в HTML — комментарий `<!-- IMG: что на этой картинке нужно -->` с описанием идеи.

### 2. Первый слайд — заголовок + первый абзац

- Структура: **картинка → `story-title` → `story-text` с первым абзацем**.
- Заголовок — название поста, разбитое на 2-3 строки через `<br>`. Не «§ РАЗДЕЛ», не кикеры.
- Первый абзац — короткий сильный зацеп. Длинные вступления разбивай на 2 слайда.

### 3. Один абзац = один слайд

- Каждый абзац исходного поста получает свой слайд.
- Порядок слайдов = порядок абзацев в источнике.

### 4. Крупные абзацы разбиваются (не сокращаются)

- Абзац длинный (>40 слов или >3 предложений) — режь по смысловым границам: на 2 или 3 слайда.
- Каждый кусок — отдельный слайд с своей картинкой (или повтором одной).
- Граница — синтаксическая (после точки, скобки, тире), а не «середина мысли».
- **Сокращать содержимое — нельзя.** Слайдов может быть 12, 15, 20 — это нормально.

### 5. Разнообразие вёрстки

Десять одинаковых «картинка сверху → текст снизу» утомляют. Чередуй паттерны:

- **TITLE** — только слайд 1.
- **BODY** — 60-70 % слайдов, рабочая лошадь.
- **QUOTE** — 1-2 на пост, для ярких тезисов и поворотных мыслей.
- **BULLETS** — если в исходнике есть перечисление или формула.
- **CLOSING** — последний слайд, с финальной мыслью.

Готовый HTML каждого паттерна — в [`slide-templates.md`](slide-templates.md). Не пиши руками — копируй оттуда.

### 6. Акценты внутри текста (разметка, не редактура)

- **`<b>` жирный** — ключевое понятие, термин, имя, цифра-якорь («**stateless-система**», «**8 316** людей», «**Hermes**»).
- **`<i>` курсив** — нюанс, оттенок, иностранное слово, внутренняя речь («*psychotic opera*», «*theory fiction*», «*Her Meeze*»).
- **Маркер-подсветка** (жёлтый / коралл / мята) — редко, только 1-2 фразы на весь пост. Перебор = комикс.
- **Цвет текста** — только на цветных/тёмных фонах для контраста.

---

## Паттерны слайдов — когда какой

| Паттерн | Когда брать | Типовое содержимое |
|---|---|---|
| **TITLE** | Слайд 1 | Картинка + `story-title` (2-3 строки) + `story-text` с первым абзацем |
| **BODY** | Любой контентный слайд | Картинка + 1-2 `story-text` |
| **QUOTE** | Центральный тезис, поворот, афоризм | Маленькая картинка + крупный `story-quote` |
| **QUOTE + tail** | Цитата + короткое продолжение | `story-quote` + `story-text-sm` после него |
| **BULLETS** | Перечисление из исходника | Картинка + `ul.story-bullets` (3-6 пунктов) |
| **CLOSING** | Последний слайд | Картинка + 1-3 `story-text-sm` (вывод, послесловие) |

---

## Фоны — ритм цвета

- **Белый и серый** чередуются по дефолту — даёт ритм.
- **Чёрный** — 1-2 слайда на пост, для ударных моментов (смерть, катастрофа, обрыв, тошнота, переломный тезис). Использовать класс `story-black`, автоматически переключает текст в белый.
- **Цветной** (`#fff176` жёлтый / `#ffb4a2` коралл / `#a5f3fc` голубой / `#bbf7d0` мята / `#e9d5ff` лаванда / `#5b21b6` фиолетовый) — **максимум 1 слайд на пост**, иначе теряется редакторский тон. Применять через `style="background:#…"`, не через класс.

---

## Картинки — подбор и подмена

- Каждая картинка несёт смысл слайда. Описание идеи — в `<!-- IMG: … -->` над слайдом.
- Если картинок больше абзацев — выбирай самые сильные. Если меньше — повторяй ключевую (обычно первую или последнюю).
- Титульный + закрывающий часто делают **bookend**: одна картинка обрамляет пост.
- **Подмена картинки** — четыре способа (подробно в `SKILL.md`):
  1. Перетащить файл из Finder / Проводника прямо на картинку.
  2. Клик по картинке → «📁 Загрузить файл».
  3. Клик → ввести URL (`images/foo.png` или `https://…`).
  4. Кнопка «🖼 Мудборд» в тулбаре (если рядом есть `moodboard-data.js`) → клик по миниатюре.

## Футер

- Футер на каждом слайде — один и тот же: `<span class="footer-sig"></span>`, справа. Оставляй его **пустым** в HTML — редактор сам подставит подпись, которую пользователь задаёт при первом открытии (адрес блога / имя) или кнопкой «✏️ Подпись». Если подпись пустая, угол остаётся чистым.
- Без слова-терма и без номера слайда. Монохромный, унифицированный по всему посту.

---

## Экспорт и сохранность

- Перед экспортом — все картинки лежат в `images/` рядом с `stories.html`. Data URL'ы (если файл залит drag-and-drop'ом) тоже экспортируются нормально, но **не сохранятся** при перезагрузке страницы — для постоянства лучше скопировать файл в `images/` руками.
- Имена картинок — семантичные (`hermes_mira_portrait.png`, `shanghai_night.jpg`), не `image1.png`.
- Финальные PNG/JPEG выходят с префиксом из `downloadOne` / `downloadAll` (по умолчанию `story-NN.png`; при желании переименуй под свой пост в JS-блоке `stories.html`).

## Что НЕ делаем

- ❌ **Не редактируем** исходный текст. Никогда.
- ❌ Кикеры `§ РАЗДЕЛ` над заголовками.
- ❌ Выпадающие из поста фразы или авторские вставки «от Claude».
- ❌ Картинка без текста (кроме случая, если это прямо запрошено).
- ❌ Повтор одной и той же вёрстки 10 раз подряд.
- ❌ Больше 1 цветного слайда на пост (кроме чёрного — его до 2).
